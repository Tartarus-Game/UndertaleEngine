# 开发待办

这份清单从对 UndergameEngine、TML233 UndertaleEngine、Zhazha 的引擎和 swapfell-remake-project 的功能对照出发，并按当前 Godot 项目重新核对。参考项目主要按源码和文档比较，尚未逐项实机验证；这里的未完成项不都意味着参考项目一定具有对应实现。详见[参考工程功能对照](FEATURE_COMPARISON.md)。

- `[x]`：写明的具体范围已有实现及对应测试，或已完成指定的文档工作；不表示完整复刻原作。
- `[~]`：该主题只有部分范围完成，具体状态见子项。
- `[ ]`：尚需实现、核对或验收。

部分完成项的子项于 2026-11-14 根据源码和现有测试核对；标记 `[x]` 的测试表示仓库中已有相应测试。三套 Godot headless 测试已在合并后的主分支 GitHub Actions 和父节点平移改动的本地测试中通过；测试只证明所列范围，不代表完整的实机或端到端验收。
